助手

OpenAI 兼容地址，自动补 /chat/completions；本地模型填 http://localhost:11434/v1，密钥留空。

后端在跑的话，配置会存到项目根目录的 .env（api key 也在里面），所有浏览器共用这一份。

自定义接口

请求体 { prompt, today, categories, tasks }，返回 { tasks: [...] } 或 { reply }。

数据

「清空数据」会把任务、回收站、长期目标与知识点、日程（时间段和非空闲）、聊天记录、兴趣标签、每日推荐全部删掉，后端那份看板数据也一起清 —— 清完会重新走一遍新用户引导。

助手里的接口地址和模型密钥（本机 .env）会留着：那是配置不是数据。想连它一起清，去上面「助手」那张卡片里改配置。
